The home view is the live event stream of what just happened across the fleet. Drill from an event into the host or container that produced it. ⌘K to jump anywhere. Atlas is a one-click flip to the spatial view (preserves the brand without gating daily work).

What's distinctive here:
1. Event timeline IS the home. Not a list of containers. The journal we already maintain becomes the front door — what just changed across the fleet, sorted by time.
2. ⌘K is the primary nav. No sidebar maze. Type to find any host / container / event / action. Linear-grade.
3. Right inspector for context. Click an event → full container/host context appears without a page change. Zero click-depth tax.
4. Atlas is a toggle, not the home. Top-right segmented control flips to the spatial fleet view when you want it. Brand surface preserved; daily friction removed.

This is genuinely new in container management. Closest existing analog is Vercel's deploy-history-as-home, but no container tool ships an event-stream-first dashboard with ⌘K nav. Click below to react, or push back in the terminal.
